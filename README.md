# 🎮 Análise de Partidas Ranqueadas de League of Legends

## 📌 Sobre o projeto

Este projeto tem como objetivo realizar uma análise exploratória e aplicar técnicas de Ciência de Dados sobre um conjunto de dados de partidas ranqueadas de **League of Legends**.

O dataset escolhido, `lol_ranked_win`, contém informações relacionadas às partidas e seus resultados, permitindo investigar quais características podem estar associadas à **vitória ou derrota** em uma partida.

A escolha deste dataset também está relacionada ao meu interesse pelo universo dos jogos, tornando o projeto uma oportunidade de aplicar conceitos de análise de dados e Machine Learning em um tema de interesse pessoal.

## 🎯 Objetivos

* Explorar e compreender as informações presentes no dataset;
* Realizar o tratamento e a preparação dos dados;
* Identificar padrões e relações entre as variáveis;
* Analisar quais características possuem maior relação com o resultado das partidas;
* Aplicar técnicas de Ciência de Dados para compreender e, quando aplicável, prever o resultado das partidas;
* Apresentar os principais resultados e conclusões obtidos durante a análise.

## 📊 Dataset

**Dataset:** `lol_ranked_win`

O conjunto de dados reúne informações de partidas ranqueadas de League of Legends, incluindo variáveis relacionadas às partidas e ao seu resultado.

> *A descrição detalhada das variáveis e a fonte do dataset serão adicionadas após a definição completa do projeto.*

## 🔎 Etapas do projeto

O projeto será desenvolvido seguindo etapas de um fluxo de análise de dados:

1. **Exploração dos dados**
2. **Limpeza e tratamento**
3. **Análise exploratória**
4. **Visualização dos dados**
5. **Preparação para modelagem**
6. **Aplicação de modelos**
7. **Avaliação dos resultados**
8. **Análise dos erros**
9. **Conclusões**

## 🚀 Resultado esperado

Ao final do projeto, espero identificar padrões presentes nas partidas e compreender melhor quais fatores estão relacionados ao resultado de uma partida ranqueada de League of Legends, utilizando técnicas de Ciência de Dados para transformar os dados das partidas em informações relevantes.
